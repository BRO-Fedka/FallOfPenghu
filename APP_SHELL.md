# Оболочка: меню, пауза, настройки, справка, сейвы

Ссылка для следующих сессий. Не сворачивать матч в `Hud`.

## Экраны

```
заставка запуска (заглушка)
  → меню (продолжить / новая / загрузить / настройки / справка / выход)
      → заставка создания мира (заглушка) + загрузка
          → матч
              → пауза: продолжить / сохранить / настройки / справка / в меню
```

«Создать мир» = новый матч на `penghu_map_v1`, не редактор карты.

Заставки входа и создания мира — заглушки, пока не решим картинку/ролик.

Одно окно на процесс. GL (или software) открывается при старте. Выход в меню
снимает карту с GPU (`GameDisplay.release_map`), контекст остаётся.
`display.quit()` не вызывать — на вебе это ломает canvas. Смена AUTO/GL/CPU
требует перезапуска.

## Стиль

Как оперативный HUD матча: Consolas, чернила `tod` hud, панели `(8, 10, 12)` с альфой, тонкая рамка, кнопки с `border_radius=3`. Не неон, не кибер-HUD, не крупные портреты.

## Порядок внедрения

1. Конечный автомат + меню. «New theater» ведёт в нынешний матч. Esc — пауза, не выход.
2. Настройки приложения (файл + одна панель в меню и на паузе).
3. Справка: вкладки, мало текста, много скринов. Меню и пауза. F1.
4. Заставки-заглушки вокруг загрузки.
5. Музыка (файлы с диска; нет файла — тишина).
6. Слоты сейва: снимок мира + Китай + часы. Не pickle `World`, не класть bake в слот.
7. Поражение Китая: стоп часов, карточка SURRENDER (время удержания, уничтоженная техника, место под рейтинг), Observe / To menu. После Observe — баннер DEFEAT в HUD.

## Что писать в сейв (когда дойдём)

Писать: часы, все объекты целиком, снаряды, транспорт, владельцы островов, состояние Китая, память разведки, камера, чат, настройки матча, отпечаток карты.

Не писать: геометрию, `sim_bake.pkl`, морской граф, GL-меши, `detection.json`.

Слоты только в `saves/`. Не трогать эталонный `penghu_map_v1/sites.json`.

## Настройки

Приложение (`saves/settings.json`): окно, полный экран, рендерер, громкости.

Матч (экран новой игры, потом в сейв): `k`, темп Китая, старт, туман, автосейв. В идущем матче из этого обычно только автосейв.

Один виджет настроек, два входа.

## Справка

Интерактивная страница с табами. Первые два — управление картой и юнитами. Дальше — короткие системы. Скрины из `assets/help/`. Нет файла — плейсхолдер с именем.

## Музыка

`assets/audio/menu.ogg`, `assets/audio/match.ogg`. Пауза матча не глушит музыку. Нет файла — игра без звука.
